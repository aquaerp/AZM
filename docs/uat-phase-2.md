# قبول المستخدم للمرحلة الثانية: المسارات التشغيلية الحرجة

تاريخ إعداد النموذج: 2026-08-21

## الهدف

التحقق ميدانياً من أن المسارات اليومية تعمل بالحسابات والصلاحيات الحقيقية، وأن المستخدم لا يحتاج إلى تسجيل الخروج والدخول لإكمال العملية. تنفذ الحالات أولاً على بيئة Staging ببيانات اختبار، ثم تكرر عينة مختصرة على الإنتاج دون إنشاء بيانات مالية وهمية.

## المتطلبات

- حسابات: مالك ورشة، موظف استقبال، فني، أمين مخزن، محاسب.
- عميل ومركبة وبطاقة عمل تجريبية وخدمة وقطعة غيار ذات كمية معلومة.
- تسجيل رقم الإصدار والبيئة ووقت التنفيذ واسم المنفذ.
- إرفاق لقطة أو رقم السجل الناتج لكل حالة، مع إخفاء بيانات العملاء الحساسة.

## حالات القبول

| الرمز | المنفذ | الإجراء | النتيجة المتوقعة | الحالة/الدليل |
|---|---|---|---|---|
| UAT-01 | المالك | إضافة عميل ثم مركبة في الجلسة نفسها | تظهر المركبة مرتبطة بالعميل دون تسجيل خروج | ☐ |
| UAT-02 | المالك/الاستقبال | فتح بطاقة وتحديد المركبة والخدمة والفني والموعد | تظهر البطاقة في الملخص وبنفس الموعد | ☐ |
| UAT-03 | الفني | بدء العمل ثم تحويل البطاقة إلى «جاهزة للتسليم» | لا يستطيع الفني تنفيذ التسليم النهائي | ☐ |
| UAT-04 | الاستقبال | تحديث الموعد ثم فتح رابط العميل | يظهر الموعد الجديد في الملخص والرابط | ☐ |
| UAT-05 | الاستقبال | تسليم بطاقة جاهزة | تسجل «تم التسليم» ووقت ومنفذ التسليم | ☐ |
| UAT-06 | أمين المخزن | إضافة مورد وتعديل اسمه وبياناته | تظهر القيم الجديدة بعد تحديث الصفحة | ☐ |
| UAT-07 | الفني/أمين المخزن | طلب قطعتين ثم صرف الطلب | تتحول حالة الطلب ويخصم المخزون بمقدار 2 | ☐ |
| UAT-08 | المحاسب | فتح الفاتورة ومراجعة الخدمات والقطع والقيم | تظهر جميع البنود وتكلفة الخدمات والقطع | ☐ |
| UAT-09 | المحاسب | تعديل قيمة بند في فاتورة مسودة | يعاد احتساب الإجمالي والضريبة فوراً | ☐ |
| UAT-10 | المحاسب | تحصيل المبلغ المتبقي بالكامل | تصبح الفاتورة مدفوعة ويمكن توليد PDF | ☐ |
| UAT-11 | المالك/المحاسب | إكمال مهمة وتسليم بطاقتها ثم احتساب الشهر | يظهر سجل العمولة بالمبلغ والأساس الصحيحين | ☐ |
| UAT-12 | جميع الأدوار | محاولة فتح الصفحات خارج الصلاحية | لا تظهر الصفحة ويرفض الخادم الطلب المباشر | ☐ |

## معيار النجاح

- نجاح الحالات الاثنتي عشرة دون إعادة تسجيل دخول غير مخطط لها.
- عدم وجود خطأ 500 أو رسالة مبهمة؛ تظهر رسالة عربية مرتبطة بالحقل أو العملية.
- تطابق أرصدة المخزون والفاتورة والعمولة مع الحساب اليدوي.
- لا يعتمد الإصدار للـPilot عند وجود فشل في UAT-03 أو UAT-07 أو UAT-09 أو UAT-10 أو UAT-11.
