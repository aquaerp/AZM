# قبول المستخدم للمرحلة الثانية: المسارات التشغيلية الحرجة

تاريخ إعداد النموذج: 2026-08-21

## الهدف

التحقق ميدانياً من أن المسارات اليومية تعمل بالحسابات والصلاحيات الحقيقية، وأن المستخدم لا يحتاج إلى تسجيل الخروج والدخول لإكمال العملية. تنفذ الحالات أولاً على بيئة Staging ببيانات اختبار، ثم تكرر عينة مختصرة على الإنتاج دون إنشاء بيانات مالية وهمية.

## المتطلبات

- حسابات: مالك ورشة، موظف استقبال، فني، أمين مخزن، محاسب.
- عميل ومركبة وبطاقة عمل تجريبية وخدمة وقطعة غيار ذات كمية معلومة.
- تسجيل رقم الإصدار والبيئة ووقت التنفيذ واسم المنفذ.
- إرفاق لقطة أو رقم السجل الناتج لكل حالة، مع إخفاء بيانات العملاء الحساسة.

## معيار النجاح

- نجاح الحالات الاثنتي عشرة دون إعادة تسجيل دخول غير مخطط لها.
- عدم وجود خطأ 500 أو رسالة مبهمة؛ تظهر رسالة عربية مرتبطة بالحقل أو العملية.
- تطابق أرصدة المخزون والفاتورة والعمولة مع الحساب اليدوي.
- لا يعتمد الإصدار للـPilot عند وجود فشل في UAT-03 أو UAT-07 أو UAT-09 أو UAT-10 أو UAT-11.
