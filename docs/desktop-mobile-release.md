# تشغيل عزم على سطح المكتب والجوال

## سطح المكتب — Windows 1.1.0

- المثبت: `desktop/release/Azm Setup 1.1.0.exe`
- النسخة المحمولة: `desktop/release/Azm 1.1.0.exe`
- يتصل كلاهما افتراضيًا بـ`https://tidesight.cloud/api`.
- يمكن تغيير الخادم من شاشة الدخول عند الحاجة.
- الحزمة الحالية غير موقعة بشهادة Code Signing تجارية، لذلك قد يظهر Windows SmartScreen عند أول تشغيل.

## تطبيق الجوال — Expo 1.1.0

- Android package: `com.azm.workshop`، و`versionCode` يساوي 2.
- iOS bundle: `com.azm.workshop`، و`buildNumber` يساوي 2.
- بيئتا EAS `preview` و`production` تتصلان بـ`https://tidesight.cloud/api`.
- نجح تصدير حزمة Android محليًا إلى `mobile/dist-android-1.1.0`.
- إنشاء APK قابل للتثبيت يتطلب رفع مصدر مجلد الجوال إلى مشروع EAS المرتبط بالحساب، ويجب اعتماده صراحة قبل التنفيذ.

## الحسابات والاشتراكات

تستخدم نسخ الويب وسطح المكتب والجوال الحسابات نفسها وقاعدة البيانات نفسها. لا تنشئ نسخة الجوال حسابات جديدة؛ يسجل الموظف الدخول بحسابه الذي أنشأه مالك الورشة. تُطبق حالات الاشتراك وحد المستخدمين على جميع التطبيقات من الخادم المركزي.
