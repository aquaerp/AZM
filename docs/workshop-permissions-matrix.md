# مصفوفة صلاحيات الورشة

الحالة: مطبقة ومحدثة لمسارات التسليم والمخزون والمحاسبة  
قاعدة العزل: لا تمنح أي صلاحية أدناه وصولًا إلى ورشة أخرى، ولا يجوز قبول `workshop_id` من العميل لتحديد نطاق العملية.

## الأدوار المستهدفة

- **المالك:** إدارة الورشة والمستخدمين والتفويضات والبيانات المالية.
- **المدير:** إدارة التشغيل، مع صلاحيات مالية يحددها المالك.
- **المحاسب:** الفواتير والدفعات والسندات والمصروفات والتقارير دون إدارة التشغيل.
- **الفني:** البطاقات والمهام المسندة إليه فقط، دون الأسعار والتقارير المالية.
- **موظف الاستقبال:** العملاء والمركبات وإنشاء بطاقات العمل والمتابعة، دون المحاسبة أو إدارة المستخدمين.
- **أمين المخزن:** الموردون وقطع الغيار ومراجعة طلبات الفنيين وصرفها، دون المحاسبة أو إدارة المستخدمين.

تجديد رمز الدخول يتم آليًا في الواجهة، بينما يؤدي تغيير الدور أو تعطيل الحساب إلى إبطال الجلسة. صلاحيات الوثائق الدقيقة بحسب درجة الحساسية ما زالت بندًا مستقلاً للتطوير اللاحق.

## ضوابط التنفيذ

- الصلاحيات تُفحص على مستوى الطلب وعلى مستوى الكائن معًا.
- السجل غير الموجود في ورشة المستخدم يعيد 404 لمنع كشف وجوده.
- لا يستطيع المستخدم منح صلاحية أعلى من صلاحياته.
- لا يستطيع آخر مالك نشط إزالة ملكيته أو تعطيل نفسه قبل تعيين مالك بديل.
- كل تغيير في الأدوار والصلاحيات وكل عملية مالية يسجل في سجل تدقيق غير قابل للتحرير من واجهة التطبيق.
- تُضاف اختبارات قبول ورفض لكل خلية فعلية في المصفوفة قبل اعتمادها.
